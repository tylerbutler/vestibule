# vestibule_github

GitHub OAuth strategy for vestibule.

> [!WARNING]
> Vestibule has not been security audited and must not be considered secure.
> It is intended for demos and prototypes that need real OAuth flows — do not
> use it in production.

## Install

```sh
gleam add vestibule_github
```

## Usage

See the [vestibule README](../../README.md) — the quick-start examples use this
package.
