## v0.0.1 - 2026-06-22


### Changed

#### Apple Sign In now carries `id_token` through `ExchangeResult.artifacts` instead of an implicit ID-token cache. `AppleCache` now only manages JWKS caching, and the `vestibule_apple/id_token_cache` module has been removed.

#### `AppleCache` and `JwksCache` are now opaque. Use `vestibule_apple.init` / `try_init` / `try_init_named` to construct an `AppleCache`; internal callers no longer access `jwks` directly.


### Security

#### Invalid or non-HTTPS redirect URIs now return `Error(ConfigError)` instead of panicking.
