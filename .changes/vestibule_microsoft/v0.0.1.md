## v0.0.1 - 2026-06-22


### Changed

#### Provider strategy now uses the opaque `strategy.new` / `strategy.user_result` / `strategy.exchange_credentials` constructors and accessors. No behavior change.


### Fixed

#### Refresh-token responses now use `RequiredScope(" ")` to match the exchange-code behavior. Previously `OptionalScope` would silently return `[]` if Microsoft omitted `scope` on refresh.


### Security

#### Invalid or non-HTTPS redirect URIs now return `Error(ConfigError)` instead of panicking.

#### Added `strategy_for_tenant(tenant_id)` for single-tenant apps. It uses tenant-specific Microsoft identity endpoints and verifies the `tid` claim in the returned ID token matches the configured tenant, failing authentication on mismatch. `strategy()` still uses `/common` (multi-tenant, no tenant enforcement) and its tenant-isolation risk is now documented.
