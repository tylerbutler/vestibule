## v0.1.0 - 2026-08-03

### Breaking

- Update middleware APIs for the vestibule `ClientConfig` and `AuthorizeOptions` split. Register configs with `config.new(client_id: id, redirect_uri: uri, auth: config.ClientSecret(secret))` or `auth: config.PublicClient`; move old config-level scopes and extra params to `config.authorize_options() |> ...` and pass them to request-phase middleware with `authorize_options:`.

### Added

- Initial release. Mist-native OAuth callback ergonomics: `request_phase`, `callback_phase`, `callback_phase_result`, and `callback_phase_auth_result` with parity to `vestibule_wisp`. State is persisted in the shared `vestibule/state_store` (ETS) and indexed by an HMAC-SHA256-signed session cookie. `Options` is constructed with `new_options(secret_key_base)` — the secret is mandatory, cookies are secure by default, and no default secret fallback exists.

### Dependencies

- Updated vestibule to 0.1.0
