# `vestibule/config`

OAuth provider configuration. Each `ProviderConfig` carries the
`client_id`, `client_secret`, `redirect_uri`, and optional per-strategy
overrides used to build authorization requests and exchange codes.

## Types

### `Config`

Provider configuration.

```gleam
pub type Config
```

## Functions

### `client_id`

Return the configured OAuth client ID.

```gleam
pub fn client_id(Config) -> String
```

### `client_secret`

Return the configured OAuth client secret.

```gleam
pub fn client_secret(Config) -> String
```

### `extra_params`

Return extra authorization query params that should be appended as-is.

```gleam
pub fn extra_params(Config) -> dict.Dict(String, String)
```

### `new`

Create a new config with the required fields and empty defaults.

```gleam
pub fn new(
  client_id: String,
  client_secret: String,
  redirect_uri: String
) -> Config
```

### `redirect_uri`

Return the redirect URI registered with the provider.

```gleam
pub fn redirect_uri(Config) -> String
```

### `scopes`

Return the configured scopes (empty list means use strategy defaults).

```gleam
pub fn scopes(Config) -> List(String)
```

### `with_extra_params`

Add extra query parameters to the authorization URL.

Reserved OAuth authorization parameters are rejected so callers cannot
override values generated by Vestibule or provider strategies.

```gleam
pub fn with_extra_params(
  Config,
  List(#(String, String))
) -> Result(Config, error.AuthError(a))
```

### `with_scopes`

Set custom scopes, replacing any defaults.

```gleam
pub fn with_scopes(
  Config,
  List(String)
) -> Config
```
